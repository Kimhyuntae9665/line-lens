# 작업 인원·속도·휴식을 함께 시험하는 가상 모델

자재·성형·검사 조건만 바꾸던 Line Lens에 **수작업 인원, 작업 속도, 정기 휴식**을 추가했습니다. 입력값은 실제 공정 처리와 대기 상태에 반영됩니다. 생산 목표와 함께 피로·부하의 가상 한도를 확인한 뒤 후보를 선택합니다.

이 문서의 계수와 한도는 교육용 가정입니다. 실제 작업자의 건강 상태, 사고 발생확률 또는 안전 인증을 계산하지 않습니다. 현장 데이터에 연결하거나 보정한 디지털 트윈도 아닙니다.

## 바꿀 수 있는 조건

| 입력 | 범위 | 계산 범위 |
|---|---|---|
| 작업자 조건 사용 | 켜짐 / 꺼짐 | 끄면 기존 v17 공정 모델을 재현 |
| 수작업 공정당 인원 | 1~3명 | 갑피준비·접착·검사 각 공정에 동일 인원 배치 |
| 작업 속도 | 90~120% | 수작업 부분만 변화, 기계 작업 부분은 유지 |
| 휴식 간격 | 60 / 90 / 120분 | 교대 시작 시각 기준으로 반복 |
| 휴식 길이 | 0 / 5 / 10분 | 세 수작업 공정의 처리를 함께 잠시 멈춤 |

자재·성형·압착에는 각 2명을 고정 배치합니다. 총 인원은 `6 + 수작업 공정당 인원 × 3`으로, 9·12·15명입니다. 인원을 한 단계 늘리는 후보는 라인 전체에서 **3명 추가**입니다. 개인별 교대·휴가·대체 인력과 서로 다른 숙련도는 구현하지 않았습니다.

## 실제 계산에 반영되는 규칙

기존 배치 처리시간에서 수작업이 차지하는 비중을 갑피준비 80%, 접착 60%, 검사 70%로 가정합니다. 나머지는 기계 작업입니다.

```text
처리시간 배수 = (1 − 수작업 비중)
              + 수작업 비중 × (2 / 배치 인원) × (100 / 작업 속도)
                × (1 + 0.25 × 현재 피로 지수 / 100)
```

1초씩 실제 처리 진행량을 누적합니다. 수작업 팀이 휴식 중이면 해당 공정의 처리는 멈추고, 앞뒤 공정은 기존 버퍼·공급·막힘 규칙대로 계속 계산됩니다. 피로가 누적되면 해당 수작업 부분이 느려집니다. 품질은 기존 고정 난수와 검사 강화 규칙을 유지하며, 피로가 불량이나 사고를 늘린다고 임의로 가정하지 않았습니다.

피로 지수는 0에서 시작해 0~100 사이로 제한합니다.

```text
작업 중: 분당 +0.10 × 수작업 비중 × (속도 / 100)² × (2 / 배치 인원)
대기 중: 분당 −0.06
휴식 중: 분당 −0.60
```

이 값은 사람의 실측 피로가 아닌 **모델 안에서 회복과 부담을 비교하는 가상 지수**입니다. 공정의 일시정지·자재 부족·후공정 막힘은 작업 시간과 구분합니다.

## 지표를 읽는 법

| 지표 | 정의 | 해석 한계 |
|---|---|---|
| 최대 피로 지수 | 세 수작업 공정에서 관찰한 피로 지수의 최댓값 | 건강 측정이나 사고확률이 아님 |
| 피로 누적 노출 | 세 수작업 팀의 매초 피로 지수/100을 시간 적분한 합 | 팀별 가상 누적량이며 개인 건강 노출량이 아님 |
| 최대 작업부하 | 각 수작업 팀의 실제 처리 시간 ÷ 휴식 제외 경과 시간 × 설정 속도 중 최댓값 | 팀별 누적 속도 가중 가동률이며 순간 최대 부하가 아님, 100%를 넘을 수 있음 |
| 버퍼 점유율 | 공정 대기공간을 평균적으로 차지한 비중 | 재공품 적체이며, 사람·운반차 동선 혼잡이 아님 |
| 휴식 시간 | 설정 달력에 따라 수작업 팀이 쉰 시간 | 개인별 실제 휴식 기록이 아님 |
| 양품/인시 | 양품 ÷ (총 배치 인원 × 교대 경과 시간) | 휴식을 포함한 배치 인시 기준 |

비교 화면의 기준 라인은 작업자 조건 사용 여부·제품·시드를 유지하고, 공정 개선을 끈 상태 및 인원 2명·속도 100%·90분마다 5분 휴식으로 계산합니다. AI 비교의 기준은 **질문 당시 사용자 설정**입니다. 둘은 비교 목적이 다르므로 라벨과 설정을 함께 확인합니다.

## 로컬 AI와 계산기의 역할

로컬 LLM은 자연어 목표를 정리하고, 계산이 완료된 후보의 허용 근거를 선택합니다. 생산량과 목표 도달 시각, 피로·부하·재공품은 시뮬레이터가 계산합니다. 목표 수량이 없는 요청에 AI가 수량을 임의로 만들지 않으며, 기본값과 제약은 사용자가 확인합니다.

작업자 조건을 켜면 기존 공정 설정 126개와 다음 네 작업자 프로필을 조합합니다: 현재 설정, 수작업 공정당 1명 추가, 속도 10%p 감소, 휴식 5분 추가 및 간격 최대 90분. 중복 프로필은 제거하므로 **최대 504개**이며 인원·속도·휴식 범위 전체를 빠짐없이 검색하는 최적화는 아닙니다. 작업자 조건을 끄면 기존 126개입니다.

양품률, 목표 달성, 공정 변경 수와 고정 조건에 더해 최대 피로·부하 한도를 적용합니다. 기본 피로 40·부하 90%는 사용자가 수정하는 **비교용 가정 한도**이며 산업 안전 기준이 아닙니다. 공정 변경 최대 3개와 작업자 조건 변경 허용은 별개입니다. 제약을 만족하는 안이 없으면 후보 없음으로 표시하고 조건을 몰래 완화하지 않습니다.

후보는 더 빠르게, 공정 변경을 적게, 부담을 낮게의 관점으로 비교합니다. 사용자가 적용을 누른 뒤에만 기존 사이드바와 3D 라인에 반영합니다. 생산만 늘리는 후보를 안전한 작업안으로 보증하지 않습니다.

## 근거와 다음 현장 검증

작업 속도·반복·지속시간과 회복을 함께 고려한다는 방향은 다음 공공기관 자료를 참고했습니다. **위 계산식과 수작업 비중을 이 자료에서 추정했다는 뜻은 아닙니다.**

- [NIOSH — Ergonomic risk factors](https://www.cdc.gov/niosh/ergonomics/ergo-programs/risk-factors.html): 힘·반복·자세의 강도·빈도·지속시간을 함께 확인합니다.
- [HSE — Managing shift work](https://www.hse.gov.uk/pubns/priced/hsg256.pdf): 부담과 회복의 균형, 작업에 따른 휴식 설계를 검토합니다.
- [OSHA — Pedestrian traffic](https://www.osha.gov/etools/powered-industrial-trucks/workplace/pedestrian-traffic): 실제 동선 위험을 보려면 보행자·장비 동선과 통로 조건을 별도로 확인해야 합니다. 현재 모델에는 동선 교차 계산이 없습니다.

실제 현장으로 확장하려면 수작업·기계 작업 시간, 배치 인원·숙련도, 휴식과 정지 기록, 작업 자세·힘·반복, 통로·운반 동선을 먼저 수집해야 합니다. 같은 조건의 교대 기록으로 생산·대기·부하를 대조한 뒤 계수를 보정합니다. 사고확률 추정은 별도의 노출·사건 데이터와 검증이 필요한 후속 범위입니다.
